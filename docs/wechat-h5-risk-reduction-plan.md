# 微信 H5 低风控改动方案（animal-test）

## 1. 背景与目标

当前项目已具备“结果页复制分享链接”能力。为了支持在微信内稳定转发并降低被风控/拦截概率，需要在**内容合规、分享链路、用户提示**三方面做优化。  
本方案目标：

- 降低被举报、被限制传播、被拦截提示“网页存在风险”的概率
- 保留测试产品的趣味性和传播性
- 优先采用纯前端低成本改动，不引入复杂后端

## 2. 改动范围

- `src/data/questions.js`：题目与结果文案降风险
- `src/views/Home.vue`：新增合规入口与基础说明
- `src/views/Result.vue`：补充合规提示与分享异常引导
- `src/components/ComplianceDialog.vue`（新增）：免责声明与隐私说明弹层
- `public/privacy.html`（可选新增）：独立隐私页面（便于外部访问）

## 3. 核心改动项

### 3.1 文案降风险（P0）

**目标**：减少高冲突、粗口、羞辱倾向表达导致的举报风险。  
**做法**：

- 扫描并替换高风险词汇（粗口、攻击性语句）
- 将“人身评价”改为“场景化自嘲/中性描述”
- 保持原题目语义和计分逻辑不变，仅替换文案

**替换原则**：

- 不改变题目选项分值（3/2/1）和结果计算逻辑
- 保持轻松幽默，但避免过激表达
- 用户读感仍然口语化、可分享

### 3.2 免责声明与隐私说明（P0）

**目标**：降低“误导性内容”与“信息收集不透明”风险。  
**做法**：

- 首页和结果页都提供“免责声明与隐私说明”入口
- 弹层文案建议包含：
  - 仅供娱乐，不构成心理诊断、医疗或职业建议
  - 当前数据默认保存在本地浏览器（说明存储范围）
  - 分享链接仅用于展示测试结果，不含敏感身份信息
  - 联系方式（邮箱/公众号）用于反馈与投诉处理

### 3.3 分享链路提示优化（P1）

**目标**：避免诱导传播文案，提升异常场景可恢复性。  
**做法**：

- 按钮提示改为中性表达，如“已复制，可粘贴到微信分享”
- 禁止出现“转发解锁/必须转发”等诱导语
- 对无效 token 提示统一文案：
  - “分享链接已失效或不完整”
  - “请让对方重新复制完整链接，或返回首页重测”
- 保留一键回首页路径，防止用户卡死

### 3.4 分享内容一致性（P1）

**目标**：减少“标题党/落地不一致”触发风控。  
**做法**：

- 分享文案与打开后的结果页核心信息保持一致
- 结果页底部固定展示“仅供娱乐”说明
- 合规文案常量化（便于后续统一改版）

## 4. 非功能约束

- 不改动计分逻辑与结果计算核心函数
- 已分享链接需尽量兼容（避免历史链接失效）
- 适配移动端展示，微信内阅读不遮挡主要 CTA

## 5. 验收标准

- 首页、结果页均可访问免责声明与隐私说明
- 文案中无粗口、强攻击性、人身羞辱措辞
- 分享文案不含诱导分享语句
- token 异常时有清晰提示与可恢复操作
- 分享文案与落地结果一致，用户无“被误导”感
- 微信内打开可稳定访问（基础网络条件下）

## 6. 实施顺序（建议）

1. **文案替换**（`questions.js`）
2. **新增合规弹层组件并接入**（`Home.vue`、`Result.vue`）
3. **分享提示与异常引导优化**（`Result.vue`）
4. **微信内自测回归**（好友聊天/群聊/朋友圈场景）

## 7. 风险与回滚

### 风险

- 文案改动过大，影响原有“好玩感”
- 提示信息过多，影响结果页转发转化

### 规避策略

- 采用“温和替换”而非全面重写
- 合规信息入口优先折叠展示，不干扰主流程

### 回滚策略

- 文案改动独立提交，可按文件快速回滚
- 弹层组件可通过开关临时隐藏

## 8. 后续可选升级

- 增加独立隐私页 + 版本号（便于法务审阅）
- 上线后加访问异常统计（识别微信内被拦截比例）
- 有后端后升级短链服务（进一步降低分享链接长度）

如确认本方案，可进入“按文件逐项落地”的实施阶段。
